# Peer Assessment Factor (PAF)

> **PAF scale: 0.0 – 1.2** > 1.0 = average contribution. Values above 1.0 reflect above-average contribution; below 1.0 reflects below-average contribution.  
> Final individual score = Group score × PAF.
>
> Evidence must match GitHub commit history and project contributions.
