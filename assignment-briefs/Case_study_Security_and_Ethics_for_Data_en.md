GROUP CASE STUDY ASSIGNMENT

Course: Security and Ethics for Data

Topic

“Security and Ethical Analysis of the Environmental Monitoring Data Manipulation Scandal in Vietnam”

⸻

1. Case Study Background

According to official investigation conclusions by Vietnamese authorities, the case involving Việt An Environmental Technology JSC, the Northern Environmental Monitoring Center, and many large industrial polluters nationwide exposed serious issues related to:

* manipulation of environmental monitoring data,
* falsification of testing and measurement results,
* forged equipment calibration records,
* environmental data tampering for corporate interests,
* collusion between monitoring organizations and polluting enterprises.

These actions resulted in:

* loss of environmental data integrity,
* concealment of actual pollution levels,
* risks to public health,
* erosion of trust in digital governance systems and the national environmental monitoring infrastructure.

According to investigation reports, involved parties allegedly:

* modified monitoring data,
* skipped actual measurement procedures,
* used fake calibration certificates,
* submitted falsified environmental data to regulatory agencies.

In modern society, environmental monitoring systems play a critical role in:

* industrial emission monitoring,
* urban environmental management,
* pollution warning systems,
* evidence-based policy making.

⸻

2. Learning Objectives

After completing this assignment, students should be able to:

1. Analyze data security risks in environmental monitoring systems.
2. Evaluate vulnerabilities that enable data manipulation.
3. Analyze ethical responsibilities of involved stakeholders.
4. Apply cybersecurity and data ethics frameworks to real-world scenarios.
5. Propose technical and governance solutions to ensure data integrity.
6. Evaluate the societal impact of corrupted data in critical systems.

⸻

3. Group Requirements

* Group size: 4–6 students
* Submission format: Group report + presentation
* Presentation duration: 15–20 minutes

⸻

4. CASE STUDY TASKS

PART A — CASE ANALYSIS (20%)

Task A1 — Case Reconstruction

Each group must:

* reconstruct the timeline of the case,
* identify involved stakeholders,
* explain how the data manipulation process worked,
* analyze motivations and benefits gained by stakeholders.

Expected Deliverables

* Case timeline
* Stakeholder map
* Manipulated data flow model

⸻

Task A2 — Environmental Data Ecosystem Analysis

Describe:

* sensors,
* monitoring devices,
* communication infrastructure,
* databases,
* regulatory agencies,
* environmental reporting systems.

Students must identify:

* where data is generated,
* how data flows through the system,
* where tampering could occur.

⸻

PART B — DATA SECURITY ANALYSIS (40%)

Students act as:

Data security auditors investigating the environmental monitoring ecosystem.

⸻

Task B1 — Data Flow & Trust Boundary Analysis

Develop:

* Data Flow Diagrams (DFD)
* Trust Boundary Diagrams

Identify:

* data collection points,
* transmission channels,
* storage locations,
* control points,
* potential tampering points.

⸻

Task B2 — Threat Modeling

Analyze possible threats and attack vectors.

Examples:

* sensor data manipulation,
* database modification,
* insider threats,
* credential abuse,
* API manipulation,
* fake calibration certificates,
* log deletion,
* alert bypassing,
* forged data submission to regulators.

Each group must apply at least one framework:

* STRIDE,
* MITRE ATT&CK,
* OWASP,
* Cyber Kill Chain.

⸻

Task B3 — CIA Triad Analysis

Evaluate impacts on:

* Confidentiality,
* Integrity,
* Availability.

Special emphasis:

Why is Integrity the most critical property in environmental monitoring systems?

⸻

Task B4 — Governance & Compliance Analysis

Evaluate compliance with:

* ISO 27001,
* NIST Cybersecurity Framework,
* Vietnamese environmental regulations,
* Data Governance principles.

Discuss:

* data governance responsibilities,
* audit trails,
* access control,
* accountability.

⸻

Task B5 — Technical Recommendations

Propose solutions including:

* anti-tampering mechanisms,
* immutable logging,
* digital signatures,
* secure IoT architectures,
* anomaly detection,
* zero-trust architectures,
* blockchain/audit-chain approaches,
* AI-based monitoring systems.

Requirements:

* solutions must be technically feasible,
* advantages and limitations must be discussed,
* recommendations should be applicable to real-world environmental monitoring systems.

⸻

PART C — DATA ETHICS ANALYSIS (30%)

Students act as:

Data ethics and public data governance consultants.

⸻

Task C1 — Ethical Violation Analysis

Analyze ethical violations related to:

* data manipulation,
* concealment of pollution,
* reporting fraud,
* abuse of authority,
* conflict of interest and collusion,
* violation of professional responsibility.

Evaluate responsibilities of:

* enterprises,
* monitoring organizations,
* regulatory agencies,
* engineers and data professionals.

⸻

Task C2 — Societal Impact Analysis

Evaluate impacts on:

* public health,
* living environments,
* nearby communities,
* public trust,
* public policy,
* scientific research,
* ESG reporting and sustainability governance.

⸻

Task C3 — Ethical Framework Application

Each group must apply at least TWO ethical frameworks.

Examples:

* Utilitarianism,
* Deontology,
* Virtue Ethics,
* Justice/Fairness Theory,
* ACM Code of Ethics,
* IEEE Ethics Principles.

Requirements:

* analysis must be concrete and evidence-based,
* avoid purely theoretical descriptions.

⸻

Task C4 — AI & Data Ethics Reflection

Discuss the following questions:

1. What happens if AI systems are trained using manipulated environmental data?
2. Can AI-driven environmental monitoring systems be trusted?
3. What are the risks of automated governance when input data is corrupted?
4. How dangerous is “data laundering”?
5. Would real-time public transparency of environmental data reduce fraud?

⸻

PART D — CRITICAL REFLECTION (10%)

Each group must answer:

1. Could similar incidents occur in smart city systems?
2. What would happen if hospital data were manipulated in similar ways?
3. Which is more dangerous:
    * data loss,
    * or incorrect data that is trusted as valid?
4. Should environmental data infrastructure be treated as critical national infrastructure?
5. Who ultimately bears responsibility:
    * engineers,
    * corporations,
    * regulators,
    * or the entire data ecosystem?
